# Домашнее задание к лекции №5

## Написать упрощённый аналог утилиты grep
Необходимо реализовать консольную утилиту mygrep, которая ищет заданный шаблон (подстроку) в указанных файлах и выводит совпавшие строки.

```bash
mygrep [-i] [-c] <шаблон> <файл> [<файл> ...]
```

Флаги:
- -i — игнорировать регистр при поиске (Hello, hello и HELLO считаются одинаковыми);
- -c — вместо строк вывести количество строк с вхождением в каждом файле.

Флаги можно комбинировать, в том числе в одном аргументе: -i -c, -ic.

### Поведение программы
Программа читает указанные файлы построчно и выводит строки, содержащие заданный шаблон (подстроку).

Формат вывода — как у настоящего grep:
- если файл один — просто содержимое совпавшей строки;
- если файлов несколько — префикс с именем файла: имя_файла:строка.

С флагом -c выводится количество совпавших строк:
- для одного файла — просто число;
- для нескольких — имя_файла:число.

Если файл не существует или недоступен для чтения — программа сообщает об ошибке в stderr и продолжает обработку остальных файлов.

Обязательно проверить файл(ы) на существование перед открытием.

Реализовать наивный алгоритм поиска подстроки (по желанию — Бойера-Мура или КМП).

Код должен корректно обрабатывать строки с \r\n (Windows) и пустые строки.

Не забыть про тесты!
